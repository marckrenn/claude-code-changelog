1. **An environment and its key (operator action).** First ask, and wait for the answer: do they have an environment already, and is its key in a file on this machine, on screen or stored elsewhere (such as a password manager), or lost? In the same message tell them never to paste a key into this session. If one is pasted here, it may have leaked, so have them follow https://code.claude.com/docs/en/self-hosted-environments-deploy#after-a-suspected-compromise. Never open or print the file of a key with any tool.

   - **The key is in a file:** have them copy that file themselves, in another terminal, to `~/claude-runner-setup.key` (if that exists, `~/claude-runner-<another name>.key`; no copy if it is named so already), and say “done”. Such files are kept from you, and you don't need their own file's path. They can delete the copy when the local runner has stopped.
   - **The key is on screen or stored elsewhere:** have them paste it into a new file on this machine, `~/claude-runner-setup.key` (if that exists, `~/claude-runner-<another name>.key`), and say “done” once it is saved. If the browser still shows the key, they then check the box that says it is saved and click **Finish** (**Done** for a newly issued key). Leaving a new environment's dialog in another way can delete the environment.
   - **The key is lost** (each is shown once): have them open the environment at ${…}/admin-settings/cloud-environments, click **Issue new key** on its **Configuration** tab, enter a label, and go on as with a key on screen. Keys issued earlier go on working.
   - **They have no environment, or want another:** tell them:

   > "Open ${…}/admin-settings/cloud-environments in your browser (Admin settings → Cloud environments). Make sure **Allow self-hosted environments** is toggled on, then scroll to the **Self-hosted environments** section and click **New**. Pick a name, click **Create**, then click **Copy environment key**. It’s shown once, and the CLI’s flag calls it the environment secret. Paste it into a new file on this machine, `~/claude-runner-setup.key` (if that exists, `~/claude-runner-<another name>.key`). I’ll `chmod 600` it afterwards. Check the box confirming the key is saved and click **Finish**. Then click your new environment to open it, and copy the **Environment ID** from the **Configuration** tab (starts with `ccpool_`). Tell me the ID and say “done” when the file is saved."

   In the first three cases ask for the **Environment ID** too (on the environment's **Configuration** tab; starts with `ccpool_`). If step 2 finds runners there, look for their count to rise or fall by one, don't wait for an empty queue, and say that another runner may take their session.

   If the file was made in this step, Bash `chmod 600` on it, by its `~` path. If it says that there is no such file, the file is missing. If it fails otherwise, for example because of a sandbox, have the operator run it in another terminal. In step 3 give the file's path.
