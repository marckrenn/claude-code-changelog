- Before I run a command that carries a commit message or a comment's text, Claude Code compares that text with secrets that it finds on this computer: the passwords in git's credential files, gh's and glab's saved tokens, this checkout's .env files, token variables such as GITLAB_TOKEN, and the user's part of your remotes' addresses. If the text holds one word for word, the command isn't run, and you and I are told which kind it was, never the value.
