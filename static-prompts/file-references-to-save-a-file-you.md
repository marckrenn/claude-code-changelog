FILE REFERENCES: to save a file you can read here, don't type its base64; set contentBase64 to a file reference, sha256:<64 lowercase hex>:<its absolute path, with / between folders>. The app fills in the file's content when the call runs. A file sent this way can be up to 10 MB (about 3 MB in some cloud sessions), whatever smaller size limit this tool states, so don't decline a file for that limit.
