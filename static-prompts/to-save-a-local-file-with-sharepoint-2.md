${…} to save a local file with sharepoint_upload_file or sharepoint_update_file, don't type its base64, even if the tool's description or earlier calls in this conversation show base64. Set contentBase64 to a file reference, sha256:<the file's SHA-256, as 64 lowercase hex>:<its absolute path, with / between folders>. The app fills in the file's content when the call runs. A file sent this way can be up to 10 MB (about 3 MB in some cloud sessions), whatever smaller size limit this tool states, so don't decline a file for that limit. This works only in sharepoint_upload_file and sharepoint_update_file: other connectors can't read a file reference. If a reference is refused, do what the refusal says.
