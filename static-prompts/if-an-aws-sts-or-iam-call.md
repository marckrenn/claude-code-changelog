If an AWS STS or IAM call fails with a 403 saying that the sandbox signs only GetCallerIdentity, that limit is deliberate: such calls can return credentials the sandbox cannot mask. Do not retry it${…}, whatever other lines here say; tell the user. To allow it, they add the host named in the error to `injectHosts` on the access key id's entry (not the secret key's) in ${…}. A list replaces the default of every allowed host, so it must also hold the others the key uses; `*.amazonaws.com` keeps the AWS ones and allows no new host. If their administrator, or the app that started this session, set the mask, only they can change it.
