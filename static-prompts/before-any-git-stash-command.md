Before any git stash command: ${…} (or a folder on the way to it) is a link, names another ref, cannot be read, or is not a plain file, and git would read and write through it. If you did not set this up, remove the link, or a stash file that reads "ref: …" (the file a link leads to is not touched). Never delete HEAD itself, and at the object store or the ref table first move what a link leads to back into a plain folder at that name, since it may be your repository's own objects or refs.
