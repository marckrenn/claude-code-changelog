Refusing to use ${…} as an isolation worktree: ${…} or ${…} is a symbolic link or junction (or ${…}'s own path could not be resolved), so the worktree is not really inside ${…} and cannot be checked against ${…}'s own records. Claude Code never creates such a link. If you made it yourself, open the worktree by its real path instead, or replace the link with a real directory and recreate the worktree from ${…}. If you did not, treat the worktree as tampered with: run no git in it, copy out what you need, delete it, and recreate it from ${…}.
