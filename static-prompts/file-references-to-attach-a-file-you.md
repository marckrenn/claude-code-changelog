FILE REFERENCES: to attach a file you can read here, don't type its base64; set the attachment's content to a file reference, sha256:<64 lowercase hex>:<its absolute path, with / between folders>, and set filename to the file's name. The app fills in the file's content when the call runs. An update_draft call removes a draft's files, so to change a draft that has files, make a new draft with the same files.
