Refusing to use ${…} as an isolation worktree: it is a repository of its own (a .git directory, not a worktree's .git file) inside ${…}${…}, where only worktrees that the checkout ${…} itself made are accepted. If you or a WorktreeCreate hook cloned it there, move the clone somewhere that is not inside any checkout's .claude/worktrees directory. If nobody meant a repository to be here, do not trust it or run git in it.
