ANTHROPIC_PROFILE is set, so Claude Code won't use a Claude account sign-in made here until you unset that variable and restart. If the named profile has no working sign-in, Claude Code will stop sending your prompts once you have signed in. Signing in can also sign the named profile out. To sign in to the named profile, run `ant auth login --profile <name>` with the name in ANTHROPIC_PROFILE, then restart Claude Code.
