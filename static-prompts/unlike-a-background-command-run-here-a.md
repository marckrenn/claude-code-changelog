- Unlike a background command run here, a ${…} command started on an attached machine with `run_in_background` never notifies this session when it finishes, and nothing re-invokes you for it. When you need to know how it stands, ${…}: it shows what the command has printed, not whether it is still running. To stop it, call ${…} with the ID its result gives and "${…}". Do not end your turn expecting to be woken when it is done.
