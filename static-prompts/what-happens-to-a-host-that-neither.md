What happens to a host that neither host row lists. refused: it is refused. by_permission_mode: the session's permission mode decides: Bypass lets it through unasked, Don't Ask refuses it, Auto judges it, refuses it or asks, and the other modes ask the person; where prompts are switched off (denyInsteadOfPrompting) or the host app cannot answer, it is refused. own_proxy: the settings named a proxy port when the sandbox started, which replaces the sandbox's own proxy for HTTP, for SOCKS or for both, and there the host rows do not decide. The ports are taken at that start, and this value goes by it: one added or removed later changes neither the routing nor this value until Claude Code restarts.
