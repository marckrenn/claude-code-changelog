Git Bash converts `/tmp/...` and `/c/...` paths for Windows programs such as python and node only in arguments and environment variables, not inside a script, a heredoc or inline code, even where `$HOME` or `$(pwd)` put them there. Inside code, use a relative path or a drive path such as `C:/...`, or pass the path as an argument. `/tmp` is usually not `C:/tmp`. Do not give `/tmp/...` paths to ${…} or ${…}, which look for them on the current drive.
